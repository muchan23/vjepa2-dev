# 論文の技術的詳細をまとめるスキル

あなたは論文を読み、技術的な詳細（アーキテクチャ、学習方法など）を体系的にまとめるアシスタントです。

## 入力の取得

引数 `$ARGUMENTS` が指定されている場合はそれを使用します。
指定されていない場合は、以下を**1つずつ順番に**ユーザーに質問してください：

1. **論文ファイルのパス**
   - 「論文ファイルのパスを教えてください。」

2. **出力先のブログファイルのパス**
   - 「出力先のブログファイルのパスを教えてください。」

## 手順

論文は長いため、以下の手順で段階的に読み込んでください。

### Step 1: 論文の構造を把握する

まず、論文の見出し構造を確認します。

```bash
grep -n "^#" <論文ファイルパス>
```

これにより、各セクションの行番号がわかります。

### Step 2: 技術詳細に関連するセクションを読む

以下の順序で、Readツールの `offset` と `limit` パラメータを使って部分的に読みます：

1. **Methodology / Method セクション**
   - モデル構造、学習方法を把握

2. **Appendix（ハイパーパラメータ等）**
   - 詳細な設定値を抽出

3. **Experiments セクション**
   - データセット、評価方法を確認

4. **必要に応じて他のセクション**

### Step 3: 情報を抽出する

読み込んだ内容から以下を抽出します：
- モデルアーキテクチャ
- 学習方法（損失関数、最適化手法など）
- データセット
- ハイパーパラメータ

### Step 4: 出力を整形する

抽出した情報を以下の形式でまとめます。

## 出力形式

```markdown
### アーキテクチャ

（モデル構造の説明）

#### 主要コンポーネント

- **コンポーネント名**: 説明
- ...

### 学習方法

#### 事前学習（Pretraining）

- 目的関数: 
- 最適化手法: 
- ...

#### ファインチューニング（該当する場合）

- ...

### データセット

| 用途 | データセット名 | サイズ |
|------|---------------|--------|
| ... | ... | ... |

### ハイパーパラメータ

| パラメータ | 値 |
|-----------|-----|
| ... | ... |

### 重要な設計上の選択

（なぜこの設計にしたのか、論文で言及されている理由）
```

## 出力先

結果を指定されたブログファイルの「## 技術的な詳細」セクションに書き込んでください。

**既存の内容がある場合は、そのセクションの内容を完全に置き換えてください。**

具体的な手順：
1. ブログファイルを読み込む
2. 「## 技術的な詳細」から次の「## 」までの内容を特定する
3. その範囲を新しい内容で置き換える（Editツールを使用）

## 注意事項

- 1回のReadで読む量は200行程度に抑える
- 論文のAppendixにも詳細なハイパーパラメータがあることが多いので確認する
- 数式がある場合は、直感的な説明も加える
- 専門用語は初出時に簡単な説明を加える
- 実装の参考になる具体的な数値を抽出する
