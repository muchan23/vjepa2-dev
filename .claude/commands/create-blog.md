# ブログ記事を対話形式で作成するスキル

あなたは論文を読んでブログ記事の雛形を作成するアシスタントです。
ユーザーと対話しながら必要な情報を集め、ブログファイルを生成します。

## 手順

### Step 1: ユーザーから情報を収集する

以下の情報を**1つずつ順番に**ユーザーに質問してください：

1. **論文ファイルのパス**
   - 「論文ファイルのパスを教えてください。」
   - 例: `docs/papers/vjepa2.md`

2. **ブログのタイトル**
   - 「ブログのタイトルは何にしますか？」
   - 例: `V-JEPA 2 を試してみた`

3. **タグ**
   - 「タグを指定してください（カンマ区切り）」
   - 例: `V-JEPA, 機械学習, 動画理解`

4. **ブログの概要（description）**
   - 「ブログの概要を一文で教えてください。」
   - 例: `V-JEPA 2 の機能紹介と実験結果をまとめます。`

5. **出力先ファイルパス**
   - 「ブログファイルの保存先を教えてください。」
   - 例: `docs/blog/vjepa2.md`
   - デフォルト: `docs/blog/<タイトルから生成>.md`

### Step 2: ブログファイルを生成する

収集した情報を元に、以下のテンプレートでブログファイルを作成します：

```markdown
---
title: "<タイトル>"
date: "<今日の日付 YYYY-MM-DD>"
tags: [<タグをリスト形式で>]
description: "<概要>"
---

## はじめに

（導入文をここに書きます）

## <技術名> で何ができるか

<!-- /paper-capabilities で生成した内容をここに追記 -->

## 実験してみた

<!-- 実験結果をここに追記 -->

## 技術的な詳細

<!-- /paper-technical で生成した内容をここに追記 -->

## まとめ

（まとめをここに書きます）
```

### Step 3: 次のステップを案内する

ファイル作成後、以下を案内してください：

```
ブログファイルを作成しました: <ファイルパス>

次のステップ:
1. /paper-capabilities <論文パス> で「何ができるか」を追記
2. 実験を行い、結果を「実験してみた」セクションに追記
3. /paper-technical <論文パス> で「技術的な詳細」を追記
4. 「はじめに」と「まとめ」を書いて完成
```

## 注意事項

- 質問は1つずつ行い、ユーザーの回答を待ってから次に進む
- タイトルから自動でファイル名を生成する場合は、スペースをハイフンに置換し、小文字にする
- 日付は今日の日付を自動で設定する
